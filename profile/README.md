### Related projects

| Project | Role |
| --- | --- |
| [OpenShellOrg](https://opensh.org/) · [Docs](https://docs.opensh.org/) · [GitHub](https://github.com/openshellorg) | Shell/CLI standards, SOS, entrypoint honesty |
| [HCI Nerdz](https://hci-nerdz.github.io/) · [Docs](https://hci-nerdz.github.io/docs/) · [GitHub](https://github.com/HCI-Nerdz) | HCI / UI / UX surfaces (sibling — not shell) |
| [DevCentr](https://devcentr.org/) · [Docs](https://docs.devcentr.org/) · [GitHub](https://github.com/dev-centr) | Environments, orchestration, Toolchain Management |
| [dlang-supplemental](https://github.com/dlang-supplemental) | D libraries and tooling we lean on |

OpenShellOrg works alongside [DevCentr](https://github.com/dev-centr) (environments and orchestration) and [HCI Nerdz](https://github.com/HCI-Nerdz) (HCI and UI) as sibling orgs — separate projects, shared goals. For how shells fit the stack, see [Entrypoint Dispatch](https://docs.opensh.org/shell-architecture/entrypoint-dispatch.html) and DevCentr’s [Toolchain Management Pattern](https://docs.devcentr.org/general-knowledge/explanation/infrastructure/toolchain-management.html).
