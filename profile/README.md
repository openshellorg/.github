# Open Shell Organization

Standards and tooling for better shells and CLIs.

- **SOS** — Standardized Operations Syntax (flag consistency + certification) in [open-shell-org](https://github.com/openshellorg/open-shell-org)
- **Structured shells** — endorse [Nushell](https://www.nushell.sh/); see [shell-architecture](https://github.com/openshellorg/shell-architecture) and [nu-require](https://github.com/openshellorg/nu-require)

Aligned with [Dev-Centr](https://github.com/dev-centr) (product recommends/configures; we standardize/tool).
